*Note1: 
1. When numbers of BMS are used for parallel control，each BMS ID switch must different. Each BMS is individual, there is no need to distinguish which BMS is master. 
2. If only one BMS is inserted in system, you can adjust the arrows of ID switch to 0~9，If two BMS are inserted in system, you can adjust the arrows of ID switch of one BMS to 0~9 and adjust the arrows of ID switch of the other BMS to the rest.
1.2 Start to use battery and power on
Step 1, wake up from shutdown mode (shipment mode)
The battery is shipped in shutdown mode, all the LEDs is off. There are two ways to wake up the battery pack from shipment mode. 1ST, to charge the battery pack by UPS. 2nd, press the button for more than 5 seconds. The LEDs will turn on after wake up.
Step 2, connect the power connector to UPS DC
Step 3, turn on the Breaker 
Step 4, connect battery RJ45 485 communication cable to UPS 485 interface to active battery.
Step 5, if there is no 485 communication with UPS, need to insert one “Pres” cable into RJ11 instead, to active the battery.
1.3 Connection of Battery Pack in parallel
Battery could be connected with parallel, the max parallel number is 10pcs. Battery packs communicate with CANBUS, and then one of the battery pack communication with system with RS485. And each BMS ID switch must different.

*Bit 3: Set when BMS need device fully charged.
